# Feel implementation plan

1. **Foundation.** Set up a pnpm React and TypeScript app with Vite, Tailwind, shadcn/ui, self-hosted fonts, and a responsive shell. Add an installable manifest, iOS home-screen icon, and a service worker that precaches the app for offline use.
2. **Local journal.** Store entries and preferences in IndexedDB. Show a month calendar with colored dots, a selected day's entries, and a bottom drawer for adding a check-in. Keep timestamps in local time and require a grade in every entry. Keep notes optional and allow multiple entries per day.
3. **Emotion input.** Pair the shadcn drawer and form controls with Adobe React Aria's two-dimensional input for the four-corner compass. The center records Neutral and neighboring corners can contribute weighted grades. Support 1–10 grading for the 12 core emotions, a skippable sequence through them, a research-based emotion list, and personal colors and labels that can optionally be reused.
4. **Insights.** Plot the average of recorded grades over the selected time window. Show a calendar-year intensity mosaic with one cell per date, including February 29 in leap years. Use daily peak intensity for the mosaic and support filtering to one emotion.
5. **Settings and privacy.** Use Google Material Color Utilities to generate a theme from any RGB seed. Let users configure the first weekday shown in the monthly calendar and toggle or reorder the journal sections with touch and keyboard support. Offer daily reminders while the app is running, JSON export, and confirmed data deletion. Keep the app free of accounts, analytics, and runtime calls to external services.
6. **Verification.** Test grading boundaries, calendar math, and aggregation. Build the production PWA and check the main flows in desktop and mobile browser viewports, including offline reload and persistence. iOS hardware validation requires a device.

The extended emotion list is adapted from [Cowen and Keltner's 2017 study](https://doi.org/10.1073/pnas.1702247114) and uses Lucide icons. The [shadcn component catalog](https://ui.shadcn.com/docs/components) supplies the calendar, drawer, chart frame, and standard controls. The compass uses [React Aria ColorArea](https://react-aria.adobe.com/ColorArea) for pointer and keyboard interaction. [Apple's Web Push documentation](https://developer.apple.com/documentation/usernotifications/sending-web-push-notifications-in-web-apps-and-browsers) describes the server infrastructure that would be needed to deliver reminders while the app is closed.
